# Synchronous-FIFO
Asynchronous 8x16 FIFO buffer to manage data flow between a producer and a consumer

# What is Asychronous FIFO ?
Asynchronous FIFO is a module that allows data to input the module and output the module, while maintaining the integrity of the data
it is used as a memory register that handle data flow in and out of a module act as a interface
